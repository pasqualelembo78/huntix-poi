# Huntix POI Database

Database condiviso di POI (Points of Interest) per il gioco Huntix.
Formato CSV geografico: `lat,lng,id,name,building_type,type`

## File

| File | Contenuto |
|------|-----------|
| `global_pois.csv` | Tutti i POI combinati |
| `gyms.csv` | Palestre e strutture sportive |
| `restaurants.csv` | Ristoranti e pizzerie |
| `hospitals.csv` | Ospedali e strutture sanitarie |
| `landmarks.csv` | Monumenti e punti di interesse |

## Contribuire

Per aggiungere nuovi POI, aprire una Pull Request con il formato corretto CSV.
Le coordinate devono essere WGS84 (lat, lng in decimali).
